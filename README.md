# Мой Дневник — сборка APK через GitHub

## Как собрать APK
1. Создайте новый репозиторий GitHub.
2. Загрузите все файлы и папки из этого архива в корень репозитория, сохранив структуру, включая `.github/workflows`.
3. Откройте **Actions** и разрешите GitHub Actions, если GitHub попросит.
4. Выберите **Build Мой Дневник APK** → **Run workflow**.
5. После зелёной галочки откройте запуск и скачайте артефакт **Moy-Dnevnik-APK**.
6. Распакуйте загруженный ZIP и установите `app-debug.apk` на Android.

## Важно
- Сборка бесплатна в пределах квоты GitHub Actions.
- Это debug APK для личной установки, не релизная сборка Google Play.
- Содержимое веб-приложения упаковано локально в APK.
- Упаковка сама по себе не добавляет системные напоминания в фоне. Они должны быть реализованы отдельно.
